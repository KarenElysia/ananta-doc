# ananta-doc

「無限大Ananta」Discord Botの紹介ページ(GitHub Pages)。

- 日本語版: [`docs/index.html`](./docs/index.html)
- English: [`docs/en/index.html`](./docs/en/index.html)

Bot本体のコードは非公開リポジトリで管理しており、このリポジトリは紹介ページのみを公開する目的で分離しています。

## 公開設定

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / Folder: `/docs` で公開できます。
